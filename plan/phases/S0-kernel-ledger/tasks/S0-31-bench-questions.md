# S0-31 · Вопросы о дизайне для первого bench set — сквозная задача

## Зачем

SL-08: первый bench set — около 60 вопросов об этом дизайне из реальных задач, с `trap` и `blank`. Пункты берутся из реальной работы и никогда не пересказывают документы (BN-05). Самая реальная работа над дизайном — S0, поэтому вопросы собираются сейчас, по мере возникновения, а не придумываются в S1.

## Объём

Входит:
- [plan/bench/questions.md](../../../bench/questions.md) — журнал: вопрос на английском (PR-14), ожидаемые блоки `ref` или «нет ответа», вид (`normal`, `trap`, `blank`), откуда вопрос, дата;
- правило работы: любой вопрос о дизайне, который пришлось искать во время задачи, записывается тем же днём;
- к концу S0 — не меньше 30 вопросов, из них не меньше 5 `blank`; `trap` (≤15% общих слов с текстом ожидаемого блока, BN-01) размечается скриптом в S1.

Не входит: блоки `bench-item`, разбиение `tune`/`holdout` — S1.

## Готово, когда

- [ ] в журнале ≥ 30 вопросов из реальных задач S0, ≥ 5 `blank`
- [ ] у каждого вопроса — источник: задача или PR
- [ ] ожидаемые ответы записаны до любого запуска `solve` (BN-05)

## Риски и заметки

- Журнал закрывается вместе с S0; в S1 его вопросы становятся черновиками `bench-item`, и владелец подтверждает их act (BN-06 — S2; в S1 — руками).
