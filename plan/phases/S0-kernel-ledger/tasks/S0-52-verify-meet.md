# S0-52 · Тест параллельного `verify` без 2-секундного окна

Инструмент контура проверки; нестабильный тест, замеченный при пересборке S0-51 на `main` 2026-10-08.

## Зачем

`test/tools/verify.test.ts`, случай «runs the steps at once: every step has started before any ends», нестабилен под нагрузкой полного `npm run verify` на Windows. Шаг-заглушка с `delay: "meet"` ждёт, пока все шаги отметятся в `started/`, но не дольше 2 с, и печатает `met <шаг> <видел>`. Запуск семи процессов `npm run` → `node` под нагруженным прогоном тестов бывает дольше 2 с — тогда `видел` меньше семи и ожидание `met <шаг> 7` падает (один раз при пересборке S0-51; отдельно и при повторе зелёный). Падение — от окна, а не от `scripts/verify.mjs` (PR-11).

## Объём

Входит:
- окно ожидания шага-заглушки — предохранитель `SAFEGUARD_MS` (`test/support/budget.ts`, S0-41), а не 2 с; таймаут случая — выше окна, чтобы при последовательном запуске падало ожидание `met <шаг> 7` с числом увиденных, а не таймаут;
- что показывает тест, не меняется: каждый шаг видит старт всех семи, прежде чем кончиться.

Не входит: правка `scripts/verify.mjs`.

## Тесты и фикстуры

- Прежние ожидания `verify.test.ts` без изменений.
- Стабильность: `npm run verify` зелёный несколько раз подряд.

## Готово, когда

- [ ] окно шага-заглушки — `SAFEGUARD_MS`, ожидание случая прежнее
- [ ] `npm run verify` зелёный несколько раз подряд
