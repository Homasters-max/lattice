# S0-53 · «Любое значение» в подмножестве схем — ключевое слово ядра до заморозки

## Зачем

S0-09 нашла пробел подмножества KR-18 (G-38): схема не может сказать «любое значение» — объекты закрыты, `values` — одна схема, пара типов — только с `null`, `oneOf` — только по объектам. Без этого не выражаются `params` стадии pipeline (RT-02, пример RT-Z02), `input` и `output` run (RT-14, RT-15), `answer` ленты (RT-23), вход, ожидание и варианты bench item (BN-01, BN-03) и `value` формы `fact` (TY-14, G-32). **Решение владельца 2026-10-08** (PR #54): ключевое слово ядра до заморозки — после неё это новая версия ядра (KR-03).

## Объём

Входит:
- **правка дизайна** KR-18 по решению владельца: строка подмножества «любое I-JSON значение» (KR-10); значение проверяет не ядро, а тот, кто знает его тип: `params` — тип `params` контракта при валидации pipeline (RT-02). Запись в `discussion/decisions.md`, `node discussion/tools/lint-ids.mjs`. Форма ключевого слова — решение задачи, по умолчанию `type: "any"`;
- **`checkSchema`** принимает её: рядом — только `description` и аннотации, которые не требуют `format` (G-22, G-23); форма с другими ключевыми словами — отказ KR-18;
- **`validate`** пускает любое значение, которое уже прошло canon (KR-10), и не спускается в него (KR-21);
- **`compare`**: любая схема `narrower` «любого значения» или `same` с ним; «любое значение» против другой схемы — `wider` (KR-22, G-27);
- **черновики S0-09 переходят на неё**: поля G-38 в `std/source/` (`pipeline`, `run`, `tape-entry`, `bench-item`); тест RT-Z02 в `test/ledger/std-drafts.test.ts` ждёт, что пример валиден; G-38 закрыт в разделе 12.

Не входит: проверка `params` по типу контракта при валидации pipeline (RT-02) — задача runtime; `value` формы `fact` — решение G-32 остаётся, пока задача фазы 6 его не пересмотрит.

## Тесты и фикстуры

- Фикстуры KR-18: trigger — «любое значение» с `properties` рядом; pass — поле «любое значение» с `description`.
- Векторы `validate`: строка, число, `null`, массив и объект проходят; `compare` — `narrower`, `same`, `wider` в режимах `extends` и `revision`.
