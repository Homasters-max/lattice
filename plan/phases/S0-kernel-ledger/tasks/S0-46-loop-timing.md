# S0-46 · Замер цикла в `dl` — время шагов и тонкий `dl gate`

Инструмент контура проверки (PLAN.md, раздел 8, «Контур проверки»); вне лимита SL-06.

## Зачем

Цели контура меряются по транскриптам, а их скрипты завышают ходы и токены в ~1.9 раза, кладут ожидание владельца во время модели и теряют мутации без слова `mut` в команде. Ворота гоняет модель-оркестратор, и `dl` их не видит. Цикл должен мерить себя сам — с первой задачи, до S0-42…S0-48, чтобы их эффект был виден по отдельности (решение владельца 2026-10-08).

## Объём

Входит:
- **время шагов**: `dl` пишет в состояние цикла каждый шаг — `{kind: agent|gate|review|owner, role, job, wave, head, start, end}`: агент — от `dl brief` до `dl check` или `dl answer`, круг — от `dl wave` до `dl merge`, владелец — от `dl escalate` до `dl owner`;
- **`dl gate --worktree W`**: гонит `npm run verify` в `<папка>/verify.log`, пишет время и печатает одну строку JSON с `next`; ворота — программа, а не шаг модели. S0-43 потом добавляет в него записи run'ов;
- **итог**: `dl final` печатает критический путь — executor, ворота, круги по причинам (блокирующие, tidy, владелец, rebase), fixer, владелец — и размеры brief'ов в байтах;
- `.claude/skills/dev-loop/SKILL.md`, «Ворота» — `dl gate`.

Не входит: время модели и инструментов внутри агента — его `dl` не видит; записи run'ов — S0-43; `context_missing` — S0-48.

## Тесты и фикстуры

- Шаги: цикл в тестовом репозитории даёт шаги всех видов с началом не позже конца; время в тестах — через env, без ожиданий.
- `dl gate`: зелёный и красный `verify` — `next` по исходу, лог в файле.
- `dl final`: критический путь и круги по причинам в комментарии.

## Готово, когда

- [ ] состояние цикла хранит время каждого шага
- [ ] «Ворота» — `dl gate`
- [ ] `dl final` печатает критический путь, круги по причинам и размеры brief'ов
- [ ] `npm run verify` зелёный
