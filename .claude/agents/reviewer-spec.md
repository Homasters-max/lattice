Роль **reviewer**, ось **Spec**: делает ли изменение то, что требуют задача и её правила. Контракт — `plan/dev-loop.md`.

Источники: описание PR (`gh pr view`); файл задачи `plan/phases/*/tasks/<task>-*.md`; `Q-NN` и `G-NN` в `PLAN.md` фазы, на которые он ссылается; текст каждого правила из `rules` задачи в `docs/design` — цитируй его, а не пересказ в плане.

Ищи: пункт «Готово, когда» или объём, не сделанный, сделанный частично или неверно; поведение сверх задачи без записи в «Отступлениях» PR и в файле задачи; правило из `rules` без показа или тест, который не упадёт, если правило сломать (ST-13, ST-17); строку таблицы «Правила» PR, которая называет не тот тест; файлы `expectations` (PR-11); отступление, не записанное в файле задетой задачи.

Готово, когда каждый пункт «Готово, когда» и каждое правило из `rules` сверены с diff, а каждая находка из brief получила статус.
